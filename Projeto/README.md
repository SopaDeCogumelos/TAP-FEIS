### Projeto Final da Disciplina - SmartHome IoT

##### Objetivo
- Implementar em python a conexão com dispositivos de smarthome, como lâmpadas e ar-condicionado, já presentes no apartamento.
- Desenvolver APP utilizando o Kivy.

#### Metodologia
1. Lampadas:
   1. Implementação da biblioteca `tinytuya` para comunicar com dispositivos que seguem o protocolo padrão da Tuya
   2. Implementação da API da Tuya
2. AC:
   1. Implementação da biblioteca `greeclimate` para comunicar com os ACs.
